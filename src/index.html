Second brain

Leggi, scrivi e collega le note del second brain, direttamente sulla repo GitHub. Ogni salvataggio è un commit; il grafo si aggiorna da solo.

Come ottengo il token (2 minuti)
  1. Apri GitHub → Fine-grained token.
  2. Resource owner: voltalacarta. Expiration: 90 giorni.
  3. Repository access → Only select repositories → second-brain.
  4. Permissions → Contents: Read and write. Facoltativo: Actions: Read (per vedere quando il grafo è aggiornato).
  5. Generate token, copialo e incollalo qui sopra.

Il token resta solo in questo browser e viene inviato soltanto a api.github.com. Senza «Ricorda» sparisce quando chiudi la scheda.
